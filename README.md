# C++ Container Benchmarks

Benchmarking the performance of various C++ associative container implementations:
insertion and lookup across different element counts (from 2 to 67 108 864).

## Containers tested

| Container | Library | Data structure |
|---|---|---|
| `std::map` | STL | Red-black tree |
| `std::unordered_map` | STL | Chaining hash table |
| `absl::flat_hash_map` | [Abseil](https://abseil.io/) | Open-addressing, SSE2 metadata |
| `boost::container::flat_map` | [Boost.Container](https://www.boost.org/doc/libs/release/libs/container/) | Sorted contiguous array |
| `boost::unordered::unordered_flat_map` | [Boost.Unordered](https://www.boost.org/doc/libs/release/libs/unordered/) | Open-addressing, SIMD group probing |
| `boost::unordered::unordered_node_map` | [Boost.Unordered](https://www.boost.org/doc/libs/release/libs/unordered/) | Node-based open-addressing |
| `boost::intrusive::set` | [Boost.Intrusive](https://www.boost.org/doc/libs/release/libs/intrusive/) | Intrusive red-black tree (no allocations) |

`Data` = `{ float a; int b; }` (8 bytes).
All hash maps pre-allocated with `reserve(n)` before insertion.

## Dependencies

- **CMake** ≥ 3.22
- **GCC** or **Clang** with C++23 support
- **Boost** ≥ 1.81 (`libboost-all-dev`)
- **Abseil** (`libabsl-dev`)
- **Google Benchmark** v1.8.0 (downloaded automatically via FetchContent)
- **Python 3** + `matplotlib`, `numpy` — for chart generation

```bash
# Ubuntu/Debian
sudo apt install libboost-all-dev libabsl-dev
pip3 install matplotlib numpy
```

## Build

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
```

## Run

```bash
# Run all benchmarks and save results
./build/hello_benchmark --benchmark_out=results.json --benchmark_out_format=json

# Generate chart
python3 plot_results.py

# Run a specific container only
./build/hello_benchmark --benchmark_filter="BM_MapLookup<AbslFlatHashMap>"

# Run insertion benchmarks only
./build/hello_benchmark --benchmark_filter="BM_MapInsertion"
```

## How the benchmarks work

All map benchmarks use two template functions:

```cpp
template <typename MapType>
static void BM_MapInsertion(benchmark::State& state);  // creates container and inserts N elements

template <typename MapType>
static void BM_MapLookup(benchmark::State& state);     // finds N elements in a pre-filled container
```

Registration via `BENCHMARK_TEMPLATE` — adding a new container takes 2 lines:

```cpp
using MyMap = my::custom_map<uint32_t, Data>;
BENCHMARK_TEMPLATE(BM_MapInsertion, MyMap)->RangeMultiplier(2)->Range(2, 1 << 26);
BENCHMARK_TEMPLATE(BM_MapLookup,    MyMap)->RangeMultiplier(2)->Range(2, 1 << 26);
```

`boost::intrusive::set` uses dedicated functions since it requires a pre-allocated node pool
(`g_nodes`) — the container does not own its elements.

Input data consists of random `uint32_t` values with a fixed seed (`mt19937(42)`),
values are `struct Data { float a; int b; }`.
